# snipr_backend

This is the Spring Boot backend for **Snipr**, a URL shortening service like Bitly.

## Features

- User registration and authentication
- Shorten long URLs
- Track clicks on shortened URLs
- Dashboard to view URL stats

## Tech Stack

- Java 17
- Spring Boot
- Spring Security + JWT
- MySQL
- Maven

## Getting Started

### Prerequisites

- Java 17
- Maven
- MySQL

### Setup

```bash
git clone https://github.com/manjunathbhandari98/snipr_backend.git
cd snipr-backend
./mvnw spring-boot:run
